# Classification requirements

Classify motorcycle-related Facebook captions and OCR into an analytics workbook with four sheets: Posts, Offers, PricePoints and Addons. Use only source-supported facts. Keep missing values blank, preserve model-price alignment and distinguish campaign eligibility from pictured examples.

Treat financial promotions, advertised pricing and add-ons as independent dimensions. Preserve source context, engagement metadata and provider-reported usage. Never publish real input data or generated workbooks.
